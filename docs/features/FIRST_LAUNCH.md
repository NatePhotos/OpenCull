# First-launch overview

A new, empty profile opens a short overview of opening/ingesting a shoot,
culling with flags and ratings, and finishing a card review or using Ship.
Common shortcut keys come from the live binding table, including custom keys.

Dismissal saves `onboardingSeen` locally. Existing profiles keep their normal
launch. This per-installation marker is excluded from exported settings. The
overview can be reopened with Settings → Keyboard → Quick overview; the shortcut
editor stays in that tab. Photo shortcuts and update prompts stand aside while
the overview is open. Self-test runs skip it.
