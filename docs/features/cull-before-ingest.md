# Cull before importing

Ingest from Card → select a source → Start Culling opens the existing workspace directly on the card. Review keeps ratings, flags, colours and crops in a local saved session; source XMP and embedded JPEG writes are bypassed even when normally enabled. Resume card session on Home restores the latest session; disconnected cards must be reconnected.

During a card review the toolbar says **Card review** beside the folder name, and **Finish review** takes the place of Ship. Finish review opens a dialog laid out like Ship: which photos on the left, where they go on the right. It copies; nothing is imported in place, so every review ends with a folder of the chosen photos. By default only what was marked is copied: photos flagged as picks and photos with five stars. The photographer can instead copy the current selection, any mix of flags, ratings and colours (a photo matching any one is copied; each chip shows how many photos carry it), or every photo in the review (the ones chosen to cull from the card). The choices and the destination are remembered for the next card. The copy uses the existing staged, size-checked transfer path with collision renaming and writes marks/crops only at the destination. A RAW and its JPEG travel together. Completed copies are recorded for retry after cancellation or failure; retries retain the chosen destination. Sessions live in the native application data directory, separately from configuration.

Move and Ship cannot bypass this workflow. Deleting remains an explicit source action and always asks during card review. Reject never deletes. Ordinary folder culling retains its existing sidecar behavior.

Validation: frontend tests include local-only marks/crops/undo and forced deletion confirmation. Rust tests check unchanged source bytes, destination sidecars, paired copying, source-destination refusal, and session persistence. Run `npm test`, `npm run build`, and a native desktop smoke test. This branch works independently; integration with multi-card selection is separate.
